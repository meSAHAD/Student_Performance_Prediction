# Project Overview

Student performance prediction is an important application of Artificial Intelligence in modern education systems. Early prediction of academic outcomes can help institutions identify struggling students, improve intervention strategies, and support personalized learning.

This project applies Machine Learning and ensemble learning techniques to analyze educational, demographic, and behavioral factors in order to predict student academic performance.

The system demonstrates a complete end-to-end Machine Learning workflow including:

- Data preprocessing
- Exploratory Data Analysis
- Feature engineering
- Model training
- Hyperparameter tuning
- Ensemble learning
- Cross-validation
- MLflow experiment tracking
- Prediction system implementation

# Dataset Information

The project uses a Bangladesh student performance dataset containing educational, demographic, and behavioral attributes.

## Features Used

| Feature | Description |
|---|---|
| Age | Student age |
| Tuition Fee | Tuition-related information |
| Time with Friends | Social interaction factor |
| SSC Result | Previous academic performance |
| HSC Result | Prediction target |

## Clone the Repository
